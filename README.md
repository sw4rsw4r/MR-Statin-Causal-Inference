# MR-Statin-Causal-Inference

Scripts for proportional colocalization and multivariable Mendelian randomization around HMGCR and related lipid genes (LPL, ANGPTL4, and PCSK9). The analyses link these instruments to coronary artery disease, type 2 diabetes, and outcomes relevant to statin effects.
